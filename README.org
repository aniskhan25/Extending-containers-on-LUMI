#+TITLE: Extending Containers on LUMI — JAX
#+AUTHOR: Anis Rahman
#+OPTIONS: toc:nil
#+OPTIONS: num:nil

This guide shows how to build the JAX container on LUMI and use it to run
JAX workloads on MI250x GPUs.

The container extends the LUMI AI Factory MPICH layer
(=/appl/local/laifs/containers/lumi-multitorch-u24r70f21m50t210-20260513_121430/lumi-multitorch-mpich-u24r70f21m50t210-20260513_121430.sif=), which
provides ROCm, libfabric, and MPICH pre-configured for MI250x — without the
PyTorch overhead of the full container.
JAX is installed with its pre-built ROCm wheels and the common ecosystem
packages (Optax, Flax).

* Build the container

Container builds require significant memory. Allocate resources on a login node first:

#+BEGIN_SRC bash
export PROJECT=<your-project>
export SIF=/scratch/$PROJECT/$USER/jax-lumi.sif
#+END_SRC

#+BEGIN_SRC bash
srun --account=$PROJECT --partition=small --ntasks=1 --cpus-per-task=8 --mem=120G --time=02:00:00 --nodes=1 --pty bash
#+END_SRC

Then load the required modules and build:

#+BEGIN_SRC bash
module purge
module load CrayEnv
module load PRoot

mkdir -p /tmp/$USER
export SINGULARITY_TMPDIR=/tmp/$USER
export SINGULARITY_CACHEDIR=/tmp/$USER

singularity build $SIF jax-lumi.def
#+END_SRC

Verify the build:

#+BEGIN_SRC bash
singularity test $SIF
#+END_SRC

* Run JAX workloads

Allocate a GPU node interactively:

#+BEGIN_SRC bash
srun --account=$PROJECT --partition=dev-g --ntasks=1 --cpus-per-task=8 --gpus=1 --mem=60G --time=01:00:00 --nodes=1 --pty bash
#+END_SRC

Load the Singularity bindings module so JAX can access the MI250x GPUs:

#+BEGIN_SRC bash
module use /appl/local/laifs/modules
module load lumi-aif-singularity-bindings
#+END_SRC

Verify JAX can see the GPUs:

#+BEGIN_SRC bash
singularity exec $SIF python3 -c "import jax; print(jax.devices())"
#+END_SRC

Run a script:

#+BEGIN_SRC bash
singularity exec $SIF python3 /path/to/your_script.py
#+END_SRC
