#+TITLE: Extending Containers on LUMI — Anemoi
#+AUTHOR: Anis Rahman
#+OPTIONS: toc:nil
#+OPTIONS: num:nil

This guide shows how to build the Anemoi container on LUMI and use it to run
the training jobs in [[https://github.com/aniskhan25/anemoi-demo][anemoi-demo]].
The container extends the LUMI AI Factory multi-framework container
(=/appl/local/laifs/containers/lumi-multitorch-latest.sif=) and bakes in the
full Anemoi training stack, so no per-run virtual environment setup is needed.

* Build the container

Container builds require significant memory. Allocate resources on a login node first:

#+BEGIN_SRC bash
export PROJECT=<your-project>
export SIF=/scratch/$PROJECT/$USER/anemoi-lumi.sif
#+END_SRC

#+BEGIN_SRC bash
srun --account=$PROJECT --partition=small --ntasks=1 --cpus-per-task=8 --mem=120G --time=02:00:00 --nodes=1 --pty bash
#+END_SRC

Then load the required modules and build:

#+BEGIN_SRC bash
module purge
module load CrayEnv
module load PRoot

mkdir -p /tmp/$USER
export SINGULARITY_TMPDIR=/tmp/$USER
export SINGULARITY_CACHEDIR=/tmp/$USER

singularity build $SIF anemoi-lumi.def
#+END_SRC

Verify the build:

#+BEGIN_SRC bash
singularity test $SIF
#+END_SRC

* Run the Anemoi demos

Clone the demo repository and configure the environment to point at the
container built above. The venv is baked into the container at
=/opt/anemoi-venv=, so set =ANEMOI_VENV= to that path instead of creating
a new one.

#+BEGIN_SRC bash
git clone https://github.com/aniskhan25/anemoi-demo
cd anemoi-demo
#+END_SRC

Edit =env/lumi-env.sh= and set:

#+BEGIN_SRC bash
CONTAINER="${CONTAINER:-$SIF}"
ANEMOI_VENV="${ANEMOI_VENV:-/opt/anemoi-venv}"
#+END_SRC

Skip =scripts/install_venv.sh= — the container already contains all
dependencies.

Submit a minimal single-GPU validation job to confirm everything works:

#+BEGIN_SRC bash
sbatch jobs/validate_minimal.sh
#+END_SRC

Once that passes, proceed to the multi-GPU and multi-node jobs as described in
the anemoi-demo README.
